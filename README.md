**Ride Radar 2.0**

**About**

Ride Radar is a motorcycle social network for finding rides, connecting with riders, and sharing safety alerts.

**Edit the code in your local development environment**

**Prerequisites:** 

1. Clone the repository using the project's Git URL 
2. Navigate to the project directory
3. Install dependencies: `npm install`
4. Create an `.env.local` file using `.env.example`

```bash
npm install
npm run dev
```

**Build**

```bash
npm run build
```
