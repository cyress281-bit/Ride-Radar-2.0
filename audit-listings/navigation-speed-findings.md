## Notes for Claude Code Review

1. The `vendor-maplibre` leak is the single most important finding. It requires tracing the exact shared module that caused the main chunk to depend on it. I suspect a Rollup CJS-interop helper (`_mergeNamespaces`) was placed in `vendor-maplibre` because that's where Rollup first encountered it, but proving this requires source-map analysis or a build with `--sourcemap` and `rollup-plugin-analyzer`.
2. The BottomNav preload omission is a clear, safe, high-impact win that should be batched immediately.
3. The prefetch helpers are a free performance gain — the code already exists, it just needs to be called.
4. `refetchOnMount: false` is safe for most pages but needs per-page verification for chat (realtime may already cover it).
